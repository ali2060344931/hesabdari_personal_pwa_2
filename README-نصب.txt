راهنمای نصب حسابداری شخصی روی گوشی

برای نصب وب‌اپ و اجرای آفلاین، فایل‌ها باید روی نشانی امن HTTPS قرار بگیرند. باز کردن فایل HTML از حافظه گوشی به‌تنهایی نصب کامل را فعال نمی‌کند.

مراحل پیشنهادی با GitHub Pages:
۱) یک مخزن جدید در GitHub بسازید.
۲) فایل‌های داخل این بسته را در ریشه مخزن بارگذاری کنید.
۳) نام فایل hisab-personal.html را به index.html تغییر دهید (یا فایل index.html داخل بسته را بارگذاری کنید).
۴) در Settings > Pages، انتشار از شاخه اصلی و پوشه root را فعال کنید.
۵) نشانی HTTPS ساخته‌شده را در Chrome گوشی باز کنید.
۶) از منوی ⋮ گزینه «نصب برنامه» یا «افزودن به صفحه اصلی» را بزنید.

برای iPhone: نشانی HTTPS را در Safari باز کنید، Share را بزنید و Add to Home Screen را انتخاب کنید.

اطلاعات تراکنش‌ها فقط در همان مرورگر و گوشی ذخیره می‌شوند. از پشتیبان‌گیری داخل برنامه استفاده کنید.

فونت وزیرمتن به‌صورت محلی در بسته قرار دارد؛ برای اجرای آفلاین، فایل vazirmatn.woff2 را کنار index.html نگه دارید. مجوز فونت در فایل OFL-Vazirmatn.txt آمده است.

انتقال اطلاعات بین مرورگرها: در برنامهٔ قبلی «پشتیبان‌گیری» را بزنید؛ سپس در مرورگر جدید «بازیابی پشتیبان» را بزنید و فایل JSON ذخیره‌شده را انتخاب کنید. هنگام بازیابی، اطلاعات موجود در مرورگر مقصد جایگزین می‌شود.
